# soundcloud-ma-provider

SoundCloud provider for [Music Assistant](https://music-assistant.io) — search and stream tracks without a SoundCloud account.

## Install

```bash
pip install soundcloud-ma-provider
```

## Usage

```bash
mass-pm   # instead of music-assistant
```

Once running, the SoundCloud provider appears automatically in Music Assistant's provider list.

## Provider domain

| Domain | Description |
|---|---|
| `soundcloud_free` | SoundCloud track search and streaming |

## Requirements

- `music-assistant-plugin-manager`
- `nuvem_de_som` — SoundCloud search and stream client
